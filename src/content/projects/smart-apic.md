# Smart-Apic

Une solution innovante pour l'apiculture de précision au Burkina Faso.

## Contexte

Ce projet, incubé à l'Orange Digital Center, vise à améliorer la production apicole locale en utilisant des capteurs IoT et l'intelligence artificielle.

## Fonctionnalités

- Suivi en temps réel des paramètres environnementaux de la ruche
- Prédiction des périodes optimales de récolte
- Alertes en cas d'anomalies détectées
- Interface mobile intuitive pour les apiculteurs

## Technologies utilisées

- Python pour le backend et les algorithmes de ML
- Flutter pour l'application mobile
- Capteurs IoT pour la collecte de données
- Firebase pour le stockage et l'authentification

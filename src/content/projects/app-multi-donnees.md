# Application multi-données

Une plateforme unifiée pour la connexion et l'analyse de données provenant de multiples sources.

## Contexte

Développement d'une application web permettant d'intégrer, visualiser et analyser des données provenant de différentes sources.

## Fonctionnalités

- Import de données depuis Excel, CSV, JSON
- Connexion à des bases de données SQL
- Intégration avec diverses APIs
- Visualisation de données interactives
- Documentation API avec Swagger

## Technologies utilisées

- Python comme langage principal
- FastAPI pour le backend
- SQLite/PostgreSQL pour le stockage
- Plotly pour les visualisations
- Swagger pour la documentation

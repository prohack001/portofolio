# Évaluation de modèles ML

Analyse comparative de modèles de machine learning pour problèmes de régression et classification.

## Contexte

Projet académique visant à évaluer les performances de différents algorithmes de ML sur des jeux de données variés.

## Fonctionnalités

- Implémentation de modèles de régression (linéaire, Ridge, Lasso)
- Implémentation de modèles de classification (Random Forest, SVM, KNN)
- Évaluation selon différentes métriques (précision, rappel, F1-score, MSE, etc.)
- Visualisation des résultats

## Technologies utilisées

- Python pour l'implémentation
- scikit-learn pour les modèles de ML
- Pandas pour la manipulation des données
- Matplotlib pour la visualisation
